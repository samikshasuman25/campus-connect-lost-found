# Campus Connect — Lost & Found Portal

A beginner-friendly React web application for a college lost-and-found board.

## Features
- Browse sample lost and found listings
- Search by item, location, category, or description
- Filter by category and listing type
- Submit a new lost/found listing
- Mark listings as claimed
- Save listings in browser `localStorage`
- Responsive layout for laptop and mobile screens

## Requirements
- Node.js (LTS version)
- VS Code

## How to run on Windows
1. Extract the ZIP file.
2. Open VS Code.
3. Choose **File → Open Folder** and select the extracted `campus-lost-found-portal` folder.
4. In VS Code, choose **Terminal → New Terminal**.
5. Run:

   ```bash
   npm install
   ```

6. When it finishes, run:

   ```bash
   npm run dev
   ```

7. Open the local address shown in the terminal (usually `http://localhost:5173`) in your browser.

## Notes
- This project uses demo listings so the page looks populated at first.
- New listings are saved in the browser where you run the app; this is not a shared online database.
- Contact emails in the sample listings are placeholders. Do not enter real private details in a demo.
- Replace demo content with your own project details and take screenshots after testing.
- Check your course's submission guidelines for any required database, backend, or report sections. This starter project does not include a server-side database.
